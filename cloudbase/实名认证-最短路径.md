# 半刻 · 实名认证（更快路径）

浏览器自动化被沙箱拦住（Chrome 起不来），改为手动填。全程约 3 分钟，大部分是等审核。

## 电脑端（推荐）

1. 打开 👉 https://console.cloud.tencent.com/developer/verify
2. **微信扫码登录**（这一步只能你来，扫码 1 秒）
3. 选 **个人认证** → 点 **开始个人认证**
4. 填写基本信息：
   - 真实姓名：填你自己的（不发我、不落盘）
   - 证件类型：`身份证`
   - 证件号码：**自己填，不要发我**
   - 行业信息：应届生/上班族选 **其他** 即可（学生可选「教育」）
   - 通讯地址：填身份证上的地址或现居地址都行
5. 下一步 → 核对信息 → 选 **人脸识别** → 微信扫码小程序做人脸
6. 提交后通常 **几分钟内** 通过；通过后告诉我

## 手机端（备用）

腾讯云 App /「腾讯云助手」小程序 → 我的 → 实名认证 → 个人认证，同样的信息。

## 完成后

实名通过 → 顺手做这两步，然后**把环境 ID 发我**：
- 搜索「云开发 CloudBase」→ 开通 → 选 **免费体验版**（0 元/月）→ 地域选上海或广州
- 控制台首页复制环境 ID（形如 `banke-8g0xxxxx`）

⚠️ 身份证号只在你自己的浏览器里填过，我没有写入任何文件。填完建议删掉聊天里那条消息。
